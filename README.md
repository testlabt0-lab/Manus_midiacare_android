# MediCare Pro Mobile

تطبيق مستقل مبني بـ **Expo وReact Native** لإدارة الزيارات المنزلية والعمليات اليومية للعيادة من هاتف أندرويد. صُممت هذه النسخة كمشروع منفصل عن تطبيق الويب؛ لذلك لا تغيّر واجهة الويب ولا تشاركها الحالة التشغيلية تلقائياً.

## ما الذي يتضمنه التطبيق؟

| المجال | المتاح في النسخة الحالية |
| --- | --- |
| لوحة التحكم | مؤشرات مشتقة من سجلات الزيارات التي يضيفها المستخدم داخل التطبيق. |
| الزيارات | إنشاء زيارة محلية باسم العيادة والخدمة، ثم مراجعة السجل. |
| التشغيل اليومي | نقل الزيارة بالتتابع بين: طلب جديد، تم التعيين، في الطريق، قيد التنفيذ، ثم مكتملة. |
| الملف الشخصي | يوضح أن التطبيق منفصل حالياً، وأن ربط الخادم الآمن يمكن إضافته لاحقاً. |
| تجربة أندرويد | تصميم عمودي، شريط تنقل سفلي، دعم اللمس الاهتزازي على الأجهزة المدعومة، ومكونات مناسبة للشاشات الضيقة. |

> **ملاحظة عن البيانات:** سجلات الزيارات في هذه النسخة تعمل محلياً في جلسة التطبيق لتوضيح التدفق التشغيلي. لا يوجد اتصال حالياً بخادم تطبيق الويب ولا مزامنة بين الأجهزة.

## التشغيل أثناء التطوير

ثبّت المتطلبات من داخل مجلد المشروع، ثم شغّل Expo:

```bash
pnpm install
pnpm android
```

يمكن فتح التطبيق على جهاز أندرويد من خلال **Expo Go** والمسح الضوئي للرمز الذي يظهر في الطرفية. ولتشغيل معاينة الويب المستخدمة في الاختبار المرئي:

```bash
pnpm web
```

## التحقق قبل البناء

تشغّل الأوامر التالية اختبارات منطق انتقال الحالة وفحص TypeScript، ثم تصدّر حزمة أندرويد المصدرية للتحقق من تجميع الشفرة:

```bash
pnpm test
pnpm check
pnpm exec expo export --platform android
```

## إنشاء APK أو AAB

لإنشاء ملف قابل للتثبيت، جهّز بيئة Android SDK محلياً ثم نفّذ التحويل إلى مشروع Android أصلي:

```bash
pnpm exec expo prebuild --platform android
cd android
./gradlew assembleRelease
```

ينتج الأمر السابق ملف APK للإصدار ضمن مخرجات Gradle. أما توزيع التطبيق عبر Google Play فيتطلب إعداد توقيع إصدار مناسب وإخراج حزمة AAB موقعة، مع اختيار اسم الحزمة المعرّف في `app.json` وهو `com.medicarepro.mobile`.

## هيكل المشروع

| المسار | الغرض |
| --- | --- |
| `App.tsx` | شاشات التطبيق والتنقل السفلي ونموذج إضافة الزيارة. |
| `src/domain/clinic.ts` | نموذج الزيارة وقواعد انتقال الحالة وحساب المؤشرات. |
| `src/domain/clinic.test.ts` | اختبارات Vitest لمنطق الزيارة. |
| `src/components/ClinicStatusBadge.tsx` | شارة حالة الزيارة الموحدة. |
| `app.json` | اسم التطبيق ومعرف حزمة Android وإعدادات Expo. |
