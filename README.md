# MediCare Pro Mobile

تطبيق جوال عربي لإدارة الزيارات المنزلية الصحية، مبني باستخدام Expo Router وReact Native. تعمل هذه النسخة بوضع محلي؛ إذ تحفظ الزيارات والتنبيهات وتفضيلات المستخدم على الجهاز دون الحاجة إلى حساب أو خدمة خادم.

## الوظائف

| المجال | المتاح |
| --- | --- |
| لوحة التحكم | ملخص الزيارات، أحدث زيارة، والإجراء السريع لإضافة زيارة |
| الزيارات | إنشاء زيارة، البحث، التصفية، وتحريك الحالة من طلب جديد إلى مكتملة |
| التنبيهات | تنبيهات تلقائية للزيارات، تذكيرات صحية، وتعليم الرسائل كمقروءة |
| الحساب | تفضيلات التنبيهات، معلومات الخصوصية، وإعادة ضبط البيانات المحلية |

## التشغيل

ثبّت الحزم ثم شغّل المعاينة:

```bash
pnpm install
pnpm dev
```

وللتحقق من الشفرة ومنطق الزيارات:

```bash
pnpm check
pnpm test
```

## خصوصية البيانات

لا تجمع هذه النسخة بيانات من خادم خارجي. يُستخدم التخزين المحلي للجهاز فقط لحفظ الزيارات والتنبيهات والإعدادات، ويمكن مسحه من شاشة الحساب.
